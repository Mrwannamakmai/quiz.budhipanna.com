# สรุปงานที่ทำ — 7 ตุลาคม 2569

## ฟีเจอร์หลัก: ฟอร์มสมัครสอบธรรมศึกษาสาธารณะ

สร้างระบบสมัครสอบธรรมศึกษาแบบไม่ต้อง login ตามสเปค `docs/ux-ui/01-public-registration.md` ปรับจาก Next.js เป็น Laravel 5.8 + Blade + Vanilla JavaScript

### ฟอร์มสมัครสอบ 4 ขั้นตอน

| ขั้นตอน | รายละเอียด |
|---------|-----------|
| 1. ข้อมูลส่วนตัว | ปีการศึกษา, คำนำหน้า, ชื่อ-นามสกุล, เลขประจำตัวประชาชน (auto-format X-XXXX-XXXXX-XX-X), อายุ, วัน/เดือน/ปีเกิด, เบอร์โทร, LINE ID |
| 2. ที่อยู่/การศึกษา | บ้านเลขที่, จังหวัด → อำเภอ → ตำบล → รหัสไปรษณีย์ (cascading dropdown), ระดับการศึกษา |
| 3. ประวัติการสอบ | เคยสอบได้/ไม่เคย, ชั้นเดิม (auto-suggest ชั้นถัดไป ตรี→โท→เอก), ช่วงชั้น, เลขที่ประกาศนียบัตร, ปีที่สอบได้, จังหวัด |
| 4. ชั้นสอบ/สำนักเรียน | ชั้นที่สมัครสอบ (validate ลำดับ ตรี→โท→เอก), ชื่อสำนักเรียน, ที่อยู่สำนักเรียน (cascading dropdown), ช่องทางที่รู้จัก, สรุปข้อมูลก่อนส่ง |

### ระบบที่เกี่ยวข้อง

- **รหัสอ้างอิง**: สร้างอัตโนมัติ `REG-YYYYMMDD-XXXXXXXX`
- **ตรวจสอบซ้ำ**: ไม่ให้สมัครซ้ำด้วยเลขประจำตัวเดียวกันในรอบสอบเดียวกัน
- **ช่วงเวลารับสมัคร**: ตั้งค่าได้ 3 โหมด — อัตโนมัติ (ตามวันที่), เปิดเสมอ, ปิดเสมอ
- **ข้อมูลที่อยู่ไทย**: JSON 21 จังหวัด (~100 records ตัวอย่าง) ใช้กับ cascading dropdown
- **AJAX submission**: ส่งฟอร์มแบบ fetch API + JSON response ไม่ reload หน้า

### Export ข้อมูลผู้สมัคร

- **Export Excel (CSV)**: ดาวน์โหลดไฟล์ .csv ครบทุกฟิลด์ 35 คอลัมน์ รองรับภาษาไทย (UTF-8 BOM)
- **Export PDF**: หน้า print-friendly A4 แนวนอน สั่งพิมพ์หรือ Save as PDF จากเบราว์เซอร์


## Database: คอลัมน์ที่เพิ่ม

### ตาราง `exam_sessions`
- `registration_mode` — โหมดรับสมัคร (auto/force_open/force_closed)
- `registration_start_date` — วันเริ่มรับสมัคร
- `registration_end_date` — วันสิ้นสุดรับสมัคร

### ตาราง `exam_registrations`
- `reference_code` — รหัสอ้างอิง
- `phone`, `line_id` — ข้อมูลติดต่อ
- `age`, `birth_day`, `birth_month`, `birth_year_be` — อายุ/วันเกิด
- `house_number`, `sub_district`, `district`, `province`, `postal_code` — ที่อยู่
- `education_level` — ระดับการศึกษา
- `has_previous_cert`, `previous_level`, `previous_period`, `previous_year`, `previous_province` — ประวัติสอบ
- `office_name`, `office_sub_district`, `office_district`, `office_province`, `office_postal_code` — สำนักเรียน
- `referral_sources` — ช่องทางที่รู้จัก
- `registration_channel` — ช่องทางสมัคร (public/internal)
