# Workflow: QR Code เชิญสมัคร + ตั้งค่าช่วงเวลารับสมัคร

**Route:** `/dashboard/qrcode`
**ไฟล์หลัก:** `qrcode-generator.tsx`
**สิทธิ์:** `superadmin`, `admin` เท่านั้น (`canManageRegistrations`)

หน้านี้ทำ 2 หน้าที่รวมกันในจอเดียว: **(ก)** สร้าง/ดาวน์โหลด/พิมพ์ QR Code ชวนสมัคร และ **(ข)** ควบคุม "ช่วงเวลาที่เปิดรับสมัคร" ซึ่งมีผลตรงกับ Banner ที่ผู้สมัครเห็นในหน้า `/` (public)

## 3. โหมดช่วงเวลารับสมัคร (3 โหมด) — มีผลต่อหน้า Public ทันที

| โหมด | ความหมาย | ผลที่หน้า `/` |
|---|---|---|
| `auto` (ค่าเริ่มต้น) | เปิด/ปิดอัตโนมัติตามวันเวลาที่ตั้ง | เทียบเวลาปัจจุบันกับ start/end แสดง 3 สถานะย่อย (ยังไม่เปิด/เปิดอยู่/ปิดแล้ว) |
| `force_open` | เปิดรับสมัครเสมอ ไม่สนวันที่ที่ตั้งไว้ | ฟอร์มเปิดเสมอ ไม่มี banner นับเวลา |
| `force_closed` | ปิดรับสมัครเสมอ ไม่สนวันที่ที่ตั้งไว้ | แสดง banner "ปิดรับสมัครชั่วคราว" เสมอ |

**Badge สถานะแบบ real-time ในหน้านี้เอง:**

| เงื่อนไข | Label | class |
|---|---|---|
| mode=force_open | เปิดรับสมัคร (บังคับเปิด) | `qr-status-active` |
| mode=force_closed | ปิดรับสมัคร (บังคับปิด) | `qr-status-expired` |
| auto, ไม่ตั้งวันที่เลย | เปิดรับสมัครตลอด | `qr-status-active` |
| auto, ยังไม่ถึงวันเริ่ม | ยังไม่เปิดรับสมัคร | `qr-status-waiting` |
| auto, เลยวันหมดเขต | หมดเวลารับสมัครแล้ว | `qr-status-expired` |
| auto, อยู่ในช่วง | เปิดรับสมัคร | `qr-status-active` |

## 4. Countdown Timer (เฉพาะโหมด auto)

- ใช้ `setInterval` อัปเดตทุก 1 วินาที (`now` state) เพื่อคำนวณนับถอยหลัง
- ถ้ายังไม่ถึงวันเริ่ม → "เปิดรับสมัครในอีก X วัน Y ชั่วโมง Z นาที W วินาที"
- ถ้าอยู่ในช่วงเปิดรับ (มีวันหมดเขต) → "เหลือเวลาอีก X วัน Y ชั่วโมง Z นาที W วินาที"
- Countdown นี้ทำงาน **เฉพาะหน้า QR Code settings** (ฝั่งเจ้าหน้าที่) — หน้า public (`/`) ไม่มี countdown แบบ real-time เพียงแสดงวันที่แบบ static ตอน render

## 5. การดาวน์โหลด QR Code (PNG)

Flow การสร้างภาพดาวน์โหลด (`downloadQR`):
1. สร้าง canvas ใหม่ขนาด 520×620px (qrSize 400 + padding 60×2 + header 120 + footer 80)
2. วาดพื้นหลังขาว + ข้อความ title/subtitle ด้านบน (ใช้ font ที่กำหนดในฟอร์ม)
3. วาด QR code ตรงกลาง (เรียก `QRCode.toCanvas` ซ้ำอีกรอบในขนาด 400px)
4. วาด URL ข้อความเล็กด้านล่าง QR
5. แปลงเป็น `data:image/png` แล้วสั่งดาวน์โหลดไฟล์ `qr-registration-srd.png` ทันที (ไม่ผ่าน dialog เลือกที่บันทึก)

ปุ่ม "พิมพ์" เรียก `window.print()` ตรงบนทั้งหน้า (ไม่ได้ครอปเฉพาะ QR) — ส่วนที่มี class `no-print` (ปุ่ม action, ฟอร์มตั้งค่า) จะถูกซ่อนเวลาพิมพ์จริง

ปุ่ม "คัดลอกลิงก์" ใช้ `navigator.clipboard.writeText` แสดงข้อความ "คัดลอกแล้ว!" ชั่วคราว 2 วินาทีแล้วกลับเป็น "คัดลอกลิงก์"

## 6. ข้อสังเกต UX

- หน้านี้มีสิทธิ์จำกัดสูงสุด (เฉพาะ 2 role) เพราะกระทบ public form ของทั้งระบบโดยตรง — ถ้าตั้งผิดพลาดจะปิดกั้นผู้สมัครทั้งหมดได้ทันที แต่ **ไม่มีการยืนยัน (confirm dialog)** ก่อนกด "บันทึก" เปลี่ยนโหมด
- หัวข้อ/หัวข้อรองของ QR เป็นแค่ข้อความที่พิมพ์บน "ภาพ QR" เท่านั้น ไม่ได้ถูกบันทึกไว้ที่ server (เมื่อ refresh หน้าจะกลับเป็นค่า default "สมัครเรียนธรรมศึกษา" / "สำนักเรียนวัดสารอด" เสมอ — เป็น local state ล้วนๆ)
