# Workflow: รายงานสถิติ (Reports)

**Route:** `/dashboard/reports`
**ไฟล์หลัก:** `report-view.tsx`
**สิทธิ์:** `superadmin`, `admin`, `teacher` (`canViewReports`)

## 1. Flow

```mermaid
flowchart TD
    Enter["เข้าหน้า /dashboard/reports"] --> Guard{canViewReports(role)?}
    Guard -->|ไม่ใช่| Redirect["redirect /dashboard"]
    Guard -->|ใช่| Fetch["getAllRegistrations() (timeout 10s)"]
    Fetch --> Compute["คำนวณ 6 มิติสถิติฝั่ง client:\nชั้นธรรมศึกษา / ระดับช่วงชั้น / สถานะ /\nระดับการศึกษา / จังหวัด / ช่องทางที่รู้จัก"]
    Compute --> Render["Render เป็น Grid ของ 6 ตารางรายงาน"]
```

## 3. ตรรกะการคำนวณ (ทั้งหมดทำงานฝั่ง client, ไม่มี query เพิ่มจาก Google Sheets)

- ทุกตารางเรียง **จากจำนวนมากไปน้อย** (`sort((a,b) => b[1]-a[1])`)
- แถวที่ไม่มีค่า (ว่าง/undefined) จะถูกจัดกลุ่มเป็น **"ไม่ระบุ"** แทนการตัดทิ้ง
- คอลัมน์ "ร้อยละ" คำนวณจากยอดรวมของตารางนั้นเอง (ไม่ใช่ยอดรวมใบสมัครทั้งระบบ) ทศนิยม 1 ตำแหน่ง
- ทุกตารางมีแถว **"รวม"** ปิดท้ายเสมอ (ตัวหนา)
- **"แยกตามช่องทางที่รู้จัก"** มีตรรกะพิเศษ: ฟิลด์ `referralSources` ในชีตเก็บเป็น string คั่นด้วย `, ` (เพราะผู้สมัครเลือกได้หลายช่องทาง) จึงต้อง `split(', ')` ก่อนนับทีละช่องทาง — ผู้สมัคร 1 คนอาจถูกนับซ้ำในหลายแถวของตารางนี้ (ผลรวมของตารางนี้อาจมากกว่าจำนวนใบสมัครทั้งหมด)

## 4. ข้อสังเกต

- หน้ารายงานเป็น **snapshot ของข้อมูลทั้งหมด** ไม่มีตัวกรองช่วงวันที่/ปีการศึกษา/สำนักเรียน ใดๆ ให้เลือกดูเฉพาะช่วง (ถ้ามีหลายปีการศึกษาสะสม ข้อมูลจะปนกันหมด)
- ไม่มีปุ่ม export (Excel/CSV/PDF) สำหรับรายงาน — ดูได้ในหน้าเว็บอย่างเดียว (ต้องใช้ `window.print()` ของเบราว์เซอร์เองถ้าต้องการสำเนา แม้หน้านี้จะไม่ได้ออกแบบ print stylesheet ไว้โดยเฉพาะเหมือนหน้า print ใบสมัคร)
- ไม่มีกราฟภาพ (chart) ใดๆ ในหน้ารายงาน เป็นตารางตัวเลขทั้งหมด (ต่างจากหน้า Dashboard ที่มี bar แสดงผลเป็นภาพ)
